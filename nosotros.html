Origen Del Proyecto

Este sitio web fue desarrollado como proyecto final para la asignatura de Taller de Programación Web de la Universidad Tecnológica del Perú (UTP). El objetivo principal del sistema es solucionar el desorden de catálogos mediante una arquitectura estructurada, acelerando la localización de repuestos e integrando un módulo de administración para la gestión en tiempo real de la base de datos de productos.

Stack Tecnologico: HTML, CSS, JavaScript, PHP, MySQL
